# 验证范围与尚待实机检查的部分

本记录明确区分 CPU 自动测试、源代码接口核对、真实模型推理和听感评估。代码能生成合法请求不意味着已经听过声音；模型路径存在也不意味着 GPU 算子已经运行。

## 本次可重复的 CPU 检查

数据与训练包装器测试：

```bash
python -m pytest tests/test_dataset.py -q
python -m ruff check src/rvcre/dataset.py scripts/train_voxcpm.py tests/test_dataset.py
```

本轮已在项目 `.venv` 中通过 **14 项数据/训练包装器测试**，包括：

- 多说话人清单、引用不跨说话人/划分、相对路径整体迁移。
- 固定 seed 的重复划分；长源文件的模拟 ASR 切片保持在同一划分。
- 缺转写、未对齐长录音和时间戳 `.lab` 被正确报告，不编造对应文字。
- 立体声转单声道、16 kHz 重采样及原音保持不变。
- 已有合格转写不加载 ASR；ASR 构造明确 `local_files_only=True`。
- 本地 ASR 模型缺失时继续保留其他合格数据并列出原因。
- 歧义输入布局、非空输出目录和非法划分参数。
- LoRA 配置生成、上游调用入口、离线环境和配置相对路径契约。

这些测试使用临时正弦测试音频以及 ASR 接口替身，不是语音识别准确率或神经语音音质测试。训练包装器测试不加载 VoxCPM2 权重、不开始训练。

仓库其他服务、API、UI 和后端测试可用 `python -m pytest` 一并运行；其最新结果以当前测试输出为准，避免在文档中固定一个很快过时的总测试数。

## 没有完成、也没有声称完成

- 在用户机器或具体 Windows GPU 上执行两个完整神经后端。
- 大权重下载完整性与 GPU 首次载入的实际运行。
- 用户角色音源的识别、分离、标注或训练；当前仓库未收到这些素材。
- VoxCPM2 LoRA 的真实训练、收敛检查与微调后盲听。
- TTS 与 VC 的跨后端音色一致性、情绪保留、CER/WER、主观质量与显存/实时率测量。
- 原生 Windows、不同 CUDA 驱动和不同 GPU 代际的安装矩阵测试。
