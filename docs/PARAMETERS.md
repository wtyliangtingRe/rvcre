# 参数与测量的真实含义

本页面区分三类信息：从参考音频测到的统计、用户想要的声音特征、后端实际的生成设置。避免把一个易懂的 UI 滑杆包装成模型已经支持的独立物理控制。

## 1. 音频测量

| 字段 | 含义 | 限制 |
|---|---|---|
| `duration_seconds` / `sample_rate` | 保存的参考片段的时长与采样率 | 不是全部原音的统计 |
| `peak_dbfs` / `rms_dbfs` | 峰值、均方根幅度的 dBFS 表示 | 不是 LUFS，也不是人耳感知响度评分 |
| `clipped_sample_ratio` | 接近满幅采样点所占比例 | 只能提示可能的削波，不能还原已经损坏的声音 |
| `silence_ratio` | 基于短时 RMS 阈值的低能量帧比例 | 不是 VAD 的精确语音/静音标签 |
| `voiced_frame_ratio` | 被 pYIN 接受的有声帧比例 | 清音、气声和不确定帧不应强行计算音高 |
| `pitch_median_hz` / `pitch_p10_hz` / `pitch_p90_hz` | 可靠有声帧 F0 分布 | 反映该次发声，不等同于人的永久音域 |
| `pitch_range_semitones` | `12 × log2(P90 / P10)` | 不是对整个声音的自动音色标签 |

当前使用 librosa pYIN，分析采样率 16 kHz，搜索范围 50–800 Hz，保留有声概率至少 0.5 的帧。可靠帧不足时字段为 `null`，不填造假的默认音高。算法来源：[librosa.pyin](https://librosa.org/doc/latest/generated/librosa.pyin.html)。

年龄感、性别表现、气声、沙哑、共鸣等并没有被自动测量后填入 UI；它们在首版是用户输入的设计要求。

## 2. 声音设计 `VoiceSpec`

| 字段 | 取值 | 默认 | 实际作用 |
|---|---|---|---|
| `pitch` | `low / medium / high` | `medium` | 生成“音调偏低/中等/偏高”的语义提示，不指定绝对 Hz |
| `resonance` | `light / balanced / full` | `balanced` | 轻盈、均衡、饱满厚实的提示，不是共振峰精确位移 |
| `brightness` | -1 到 1 | 0 | 柔暗到明亮的提示强度，不是 EQ 分贝 |
| `breathiness` | 0 到 1 | 0 | 气声提示，不是声门开合率或噪声比例测量 |
| `roughness` | 0 到 1 | 0 | 沙哑质感提示，不是 jitter/shimmer 的目标值 |
| `maturity` | `young_adult / adult / mature` | `adult` | 成年声线的年龄感提示，不判定真实年龄 |
| `presentation` | `neutral / feminine / masculine` | `neutral` | 声音表现提示，不是对录音者身份的推断 |
| `description` | 最多 600 字符 | 空 | 补充场景和声线要求 |

当前数值控制会编译成有限级别的文字描述。例如轻微与明显气声是提示级别，0.40 和 0.41 未必生成不同描述。这些轴也不是正交的：提高气声可能同时影响清晰度、响度与年龄感。合理使用方式是固定试听句子，一次改少量特征，听过后再保存新候选。

声音设计每次 1–6 个候选，试听文本最多 240 字符。保存某个候选之后，后续任务使用其固定参考音频；设计参数作为来历记录，不在每次 TTS 时重新生成新身份。

## 3. TTS 表达参数 `Performance`

| 字段 | 取值 | 说明 |
|---|---|---|
| `speed` | 0.7–1.4，默认 1.0 | 当前编译为较慢/正常/较快的语言提示；不是严格的 0.8 倍或 1.2 倍 DSP 变速 |
| `emotion` | `neutral / happy / sad / angry / calm / excited` | 生成对应表达提示，不承诺所有音色都能同样准确地表达 |
| `instruction` | 最多 400 字符 | 用户补充的表达要求 |
| `seed` | 0–4294967295 | 控制本次抽样，便于相同版本内比较 |
| 文本长度 | 最多 600 字符 | 长文需按自然段提交，首版未自动拼成长篇有声书 |

两种模式：

- **`controllable`**：参考音频固定音色，表达提示控制本次说法。是首版默认模式。
- **`hifi`**：用与参考片段精确对应的转写做高保真参考克隆；额外表达参数必须恢复默认。缺少参考转写时不冒充为 Hi-Fi 模式执行。

参考被自动截取后，整段原文不能继续作为对应转写；需提供已经剪好的参考并标注实际内容。

## 4. VC 设置

| 参数 | v0.1 允许值 | 默认 | 含义 |
|---|---|---|---|
| `diffusion_steps` | 1–100 | 30 | 采样计算量；增加步骤不保证每条样本都更自然 |
| `similarity_cfg_rate` | 0–1 | 0.7 | 目标参考条件强度，需要与清晰度一起试听 |
| `intelligibility_cfg_rate` | 0–1 | 0.7 | 内容条件强度，不是“准确率百分数” |
| `length_adjust` | 仅 1.0 | 1.0 | 固定版本的纯音色分支不应用此旋钮，首版不开放伪语速控制 |
| `convert_style` | 固定 false | false | 不启用 AR 的口音/情绪转换 |
| `anonymization_only` | 固定 false | false | 使用指定参考，不转成忽略参考的“平均声音” |

官方 v2 参数入口见 [inference_v2.py](https://github.com/Plachtaa/seed-vc/blob/51383efd921027683c89e5348211d93ff12ac2a8/inference_v2.py)。

Seed-VC v2 不提供显式 F0 曲线输入。保留源录音的内容、节奏和情感是默认目标，但仍可能改变呼吸、咬字、音高和局部时长。首版没有“无损保留情绪”或“锁死旋律”的开关。

## 5. 音高控制的后续边界

之后可增加两种明确分开的控制：保留源音高曲线；或保持相对起伏、把发声区间移到目标声音的舒适范围。后者会改变绝对音高，不能用来宣称保留原调演唱。

唱歌需要独立验证 F0 条件路线，例如 Seed-VC v1 的 44.1 kHz F0 模型；v1 的 `f0_condition`、`auto_f0_adjust`、`semi_tone_shift` 不属于当前接入的 v2 参数。当前 UI 不显示不存在的功能。
